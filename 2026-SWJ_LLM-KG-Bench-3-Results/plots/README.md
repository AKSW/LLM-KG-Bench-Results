## Dimensions of the Capability Compass

The capability Compass is organized around 5 dimensions, mainly for demonstration purposes of the new LLM-KG-Bench feature to aggregate scores:

* **SPARQL Syntax 1 (Syn-1)**: Working with SPARQL queries with first answer. This includes the `0_answerParse` scores (first answer per iteration) from task types SparqlSyntaxFixing(SSF) and Text2Sparql(T2S).
* **SPARQL Syntax max (Syn-Max)**: Working with SPARQL queries with correction possibility in dialog. This includes the `max_answerParse` scores (best answer per iteration) from the same task types as Syn-1.
* **SPARQL Semantic Read (Sem-R)**: Working according to semantics of SPARQL queries. This includes the `combinedF1` score of the Sparql2Answer(S2A) task type.
* **SPARQL Semantic Write 1 (Sem-W-1)** Creating semantically correct SPARQL queries with first answer. This includes the `0_combined` scores (first answer per iteration) from Text2Sparql(T2S) task types.
* **SPARQL Semantic Write max (Sem-W-Max)**: Creating semantically correct SPARQL queries with correction possibility in dialog. This includes the `max_combined` scores (best answer per iteration) from Text2Sparql(T2S) task types.

In the plots, the mean value is indicated by the solid black line, and the blue area represents the standard deviation.
