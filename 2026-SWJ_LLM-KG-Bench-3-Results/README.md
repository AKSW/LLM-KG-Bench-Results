# Results generated with LLM-KG-Bench version 3

This repo contains [evaluation results](rawresults/) generated with [LLM-KG-Bench version 3](https://github.com/AKSW/LLM-KG-Bench/tree/v3.0.1) for 41 open and proprietary LLMs and is available at [GitHub as folder](https://github.com/AKSW/LLM-KG-Bench-Results/tree/main/2026-SWJ_LLM-KG-Bench-3-Results) and at [GitHub as branch](https://github.com/AKSW/LLM-KG-Bench-v3-0-results/tree/2025-SWJ).

This dataset is described in the article "Evaluating Large Language Models for RDF Knowledge Graph Related Tasks - The LLM-KG-Bench-Framework 3"] by Meyer et al., submitted for review 2025 at Semantic Web Journal, Special issue on Large Language Models, Generative AI and Knowledge Graphs.

An earlier version of this dataset containing evaluation results for 37 LLMs was published at ESWC 2025 Resources Track as ["LLM-KG-Bench 3.0: A Compass for Semantic
Technology Capabilities in the Ocean of LLMs](https://doi.org/10.1007/978-3-031-94578-6_16)([copy on arxiv](https://arxiv.org/pdf/2505.13098)) by Meyer et al. 2025, and the dataset is still available at [GitHub as folder](https://github.com/AKSW/LLM-KG-Bench-Results/tree/main/2025-ESWC_LLM-KG-Bench-3-Results), at [GitHub as branch](https://github.com/AKSW/LLM-KG-Bench-v3-0-results/tree/2025-ESWC), and at [zenodo ![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.15100646.svg)](https://doi.org/10.5281/zenodo.15100646)

The dataset includes:
* the [configuration](configuration.yml)
* the [raw result files](rawresults/) in the [rawresults directory](rawresults/)
* the [plots and analysis tables](plots/README.md) in the [plots directory](plots/)
* additional info for reproducing the data like [createPlots.sh](createPlots.sh) and [runBenchmark.sh](runBenchmark.sh)

The [raw result files](rawresults/) are passwort protected to reduce the chance of test data leakage into LLM training data. Please do not spread them unencrypted. You can unzip them with `Leave-Finest-Coats-Serena-Cheats-46`
